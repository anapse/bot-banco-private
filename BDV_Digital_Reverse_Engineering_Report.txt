8. COMPORTAMIENTO CRÍTICO DEL BOT (REGLAS DE ORO)
================================================================================

ESTRATEGIA PRINCIPAL:
---------------------
"Prender el bot ANTES de la subasta y enviar la orden repetidamente;
NO pre-verificar disponibilidad — se envía y el banco decide.
Al aceptar, compró primero y se detiene. Monto probado: 10 USD."

PSEUDOCÓDIGO LÓGICA PRINCIPAL:
------------------------------
async def comprar_divisas(monto_usd: float = 10.0, max_intentos: int = 20):
    """
    Estrategia: Prender ANTES de subasta, enviar repetidamente,
    NO pre-verificar disponibilidad. Banco decide.
    """
    await login()  # OAuth password grant
    
    for intento in range(max_intentos):
        try:
            # 1. LEER TASA VIVA DEL BANCO (OBLIGATORIO)
            exri = await get_exri_rules()  # GET /consultarReglasEXRI
            
            if exri['estadoPolitica'] == 'CERRADA':
                # FALLBACK MENUDEO
                mercado = await get_menudeo_mercado()
                tasa = mercado['tasaCompra']
                endpoint = '/bdvx-menudeo-v2/v1/transar'
                payload = build_menudeo_payload(monto_usd, tasa)
            else:
                # EXRI OFICIAL
                tasa = exri['tasaReferencia']  # USAR EXACTA
                endpoint = '/bdvx-operaciones-cambiarias/v1/operaciones/comprar'
                payload = build_exri_payload(monto_usd, tasa, exri['codigoRegla'])
            
            # 2. ENVIAR ORDEN (banco decide)
            response = await post(endpoint, payload)
            
            if response['status'] == 'PENDIENTE':
                # 3. CONFIRMAR CON OTP
                otp = await solicitar_clave_movil()  # O leer SMS
                confirm = await confirmar_compra(response['idOperacion'], otp)
                
                if confirm['status'] == 'APROBADA':
                    log(f"✅ COMPRA EXITOSA: {confirm['montoDivisa']} USD a {confirm['tasaAplicada']}")
                    return confirm
                    
            elif 'tasa ofertada no cumple' in response.get('message', ''):
                # Tasa cambió, reintentar inmediatamente
                continue
                
        except RateLimitError:
            await asyncio.sleep(30 * (2 ** intento))  # Backoff exponencial
            continue
        except TokenExpiredError:
            await refresh_token()
            continue
        except SessionExpiredError:
            await login()  # Re-login completo
            continue
            
    raise MaxRetriesExceeded("No se logró comprar divisas")

REGLAS DE ORO:
--------------
1. TASA SIEMPRE DEL BANCO EN VIVO — Leer /consultarReglasEXRI antes de CADA intento
2. NO PRE-VERIFICAR DISPONIBILIDAD — Enviar orden y el banco decide
3. REINTENTAR CON BACKOFF EXPONENCIAL — 5 intentos → 30s lockout
4. MONTO PROBADO: 10 USD — Con 150 USD el saldo no alcanzaba
5. EXRI → MENUDEO FALLBACK — Cuando estadoPolitica == "CERRADA"
6. SESIÓN VIVA — Mantener token refrescado y cookie ASP.NET_SessionId
7. DETENERSE AL PRIMER ÉXITO — "Al aceptar, compró primero y se detiene"
